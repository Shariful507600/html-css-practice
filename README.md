# HTML ও CSS প্র্যাকটিস (১৫টি জব + ফাইনাল প্রজেক্ট)

HTML ও CSS হাতে-কলমে শেখার জন্য সাজানো ১৫টি প্র্যাকটিস জব এবং একটি ফাইনাল প্রজেক্ট। প্রতিটি ফাইল নিজে রান করো, কোড বদলাও এবং ফলাফল দেখো।

## ফাইল চেনার নিয়ম

| ফাইল | কাজ |
|---|---|
| `.html` | ওয়েবপেজের কাঠামো |
| `.css` | ডিজাইন বা স্টাইল |

উদাহরণ: `job10_profile_card.html` এর স্টাইল আছে `job10_profile_card.css` এ।

| জব | ফাইল | বিষয় |
|---|---|---|
| ০১ | `job01_profile.html` | HTML স্ট্রাকচার, হেডিং, প্যারাগ্রাফ, ইমেজ, অ্যাঙ্কর |

জব ০১ থেকে ০৬ শুধু HTML, তাই এগুলোর CSS ফাইল নেই।

## কীভাবে রান করবে

1. সব ফাইল একই ফোল্ডারে রাখো (HTML ও CSS আলাদা ফোল্ডারে থাকলে স্টাইল কাজ করবে না)।
2. মোবাইলে **Acode** অ্যাপে ফোল্ডারটি ওপেন করো।
3. `.html` ফাইল খুলে **Run (▶)** বাটনে চাপ দাও।

## প্র্যাকটিসের নিয়ম

- শুধু রান করে ছেড়ে দিও না, `.css` ফাইলে গিয়ে কালার, সাইজ ও পজিশন নিজে বদলাও।
- বদলে আবার রান করে দেখো কী পরিবর্তন হলো।
- ভুল হলে ঘাবড়াবে না, ভুল থেকেই বেশি শেখা যায়।
- জব ০১ থেকে ১৫ ক্রমানুসারে করো, সবশেষে ফাইনাল প্রজেক্ট।

## মনে রাখবে

- ছবি দেখতে চাইলে `me.jpg`, `kusum.jpg`, `college.jpg` নামে নিজের ছবি একই ফোল্ডারে রাখো।
- জব ০৪-এর অডিও ও ভিডিও ফাইল নিজে যোগ করতে হবে।

নিজে এডিট করে দেখলে HTML ও CSS এর ফাউন্ডেশন মজবুত হবে এবং রিয়েল লাইফে ওয়েবসাইট বানানোর ধারণা পাবে।
